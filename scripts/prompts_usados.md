# Prompts de apoyo utilizados

Durante el desarrollo del proyecto se realizaron algunas consultas de apoyo para organizar mejor el trabajo.

## Modelo de clases
- Proponer un modelo de clases para una librería usando Libro, Autor y Categoria.
- Revisar los atributos, métodos y relaciones entre las clases.

## Kotlin
- Revisar la implementación de las clases en Kotlin.
- Organizar las clases dentro del paquete model.

## Jetpack Compose
- Orientar la estructura de una pantalla para listar libros.
- Orientar la estructura de una segunda pantalla para listar autores.
- Revisar el uso de componentes como Scaffold, LazyColumn, Card, Column y Text.

## Compilación
- Revisar la compilación del proyecto con Gradle.
- Verificar posibles errores y comprobar que el proyecto compile correctamente.
